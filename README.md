# CompGraf2Bim

Quando baixar o trabalho, crie uma pasta chamada "Assets", e coloque as pastas "Scripts", "Scenes" e "Prefabs" dentro da "Assets" (Também coloque os respectivos .meta)

Quando abrir o projeto os prefabs vao esar tudo na cor rosa (pois estão sem as texturas)

Abra esse link (https://assetstore.unity.com/packages/2d/textures-materials/floors/outdoor-ground-textures-12555) e baixe essa textura.

Abra o projeto na unity e faça o seguinte passo a passo para importar essas texturas:

- Clique na aba "Window"
- Abra o "Package Manager"
- Coloque em "Packages:My assets"
- Baixe e faz o import do pacote que você baixou
- Pode deixar apenas as texturas: ground2, gound4 e ground6
- Quando terminar o import, deve aplicar automaticamente as texturas
